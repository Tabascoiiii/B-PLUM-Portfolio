English

Version 1.2

Silver Tabby Cat joins the free themes. Apricot Poodle is available as a separate one-time purchase. Traditional Chinese is now supported, and the App Store presentation has been refreshed in four languages.

Version 1.1

The App Store name, descriptions, and screenshots were refreshed. Clock, Stopwatch, Countdown, and previously purchased themes continued to work as before.

Version 1.0

Initial macOS release with clock, stopwatch, countdown, and theme support.
